# DMCA designated agent registration (IC SPICY)

Use this checklist to register with the U.S. Copyright Office (~$6 as of 2026).

## Before filing

1. Create and monitor **copyright@icspicy.app** (or update `DMCA_AGENT_EMAIL` in code if you use a different inbox).
2. Confirm postal address: **IC SPICY, 20225 Renwick Ave, Port Charlotte, FL 33954**.

## Filing steps

1. Go to [https://www.copyright.gov/dmca-directory/](https://www.copyright.gov/dmca-directory/) (Copyright Office DMCA agent directory).
2. Register as service provider; add designated agent:
   - Organization: IC SPICY
   - Agent name: (owner or authorized representative)
   - Email: copyright@icspicy.app
   - Address: 20225 Renwick Ave, Port Charlotte, FL 33954
3. Pay the registration fee and save the confirmation.
4. Update the DMCA page copy in `src/frontend/src/pages/legal/DmcaPage.tsx` to remove the “not yet registered” notice once active.
5. Renew per Copyright Office schedule (check current renewal period).

## After registration

- Keep agent contact information current in the Copyright Office directory.
- Process notices and counter-notifications promptly; log actions internally.
